## Bestimmung der Vault

Ich möchte für jede Implementation eines Moduls und seiner Klassen und Funktionen eine Zettelkastenartige Dokumentation erhalten, also namentlich verlinkt sind.

## Notizkonventionen

1. Jede neue Datei erhält eine Notiz mit: Abhängigkeiten, Klassen in Stichpunkten mit kurzer Erklärung
2. Jede Klasse erhält eine Notiz mit: Parametererklärung, Liste der globalen Variablen + kurze Erklärung, Liste der Methoden + kurze Erklärung, Name der Datei in der sie definiert wird
3. Jede Methode erhält eine Notiz mit: Parametererklärung, Funktionsbeschreibung, Name der Klasse in der sie definiert wurde
4. Jeder Parameter der Klassen und Methoden erhält eine Notiz mit: Datentyp, Erklärung seiner Rolle in Klasse/Funktion, Name der Klasse/Methode in der er definiert wurde
5. Jedes importierte Modul erhält eine Notiz mit: Dem Zweck für den es importiert wurde, einer Liste der Dateien in denen sie als Abhängigkeit importiert wurde 
6. Verlinke die Namen der Dateien, Module, Methoden und Parametern man soll die Datenstruktur schnell erkunden können
7. Erzeuge eine [[Link Library]] in der alle Links unter Dateien, Klassen, Methoden, Parameter geordnet
